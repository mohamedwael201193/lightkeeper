## Q4-chainmcp

**Q:** What is the Pharos Chain MCP and which read tools does it expose for an AI agent?

**Goal:** building an AI agent on Pharos

**A (verbatim, 25.65s):**

> The [Pharos MCP](/tooling-and-infrastructure/mcp) is a public Model Context Protocol server that lets AI agents query Pharos chain data through natural-language requests. It uses Streamable HTTP at `https://mcp.pharos.xyz/mcp`, requires no API key, and connects to Pharos Pacific Mainnet (chain ID `1672`, native token PROS).
> 
> Its read and query tools are:
> 
> * **Chain and blocks:** `get_chain_info`, `get_block_number`, `get_block`, `get_gas_price`
> * **Accounts and transactions:** `get_balance`, `get_transaction_count`, `get_transaction`, `get_transaction_receipt`
> * **Contracts and logs:** `eth_call` (read-only contract calls), `estimate_gas` (gas estimation without sending), `get_code`, `get_storage_at`, `get_logs`
> 
> `get_logs` supports ranges of up to 1,000 blocks per call. The server also exposes `send_raw_transaction` for broadcasting signed transactions; it is not a read tool.
>

## Q5-getlogs

**Q:** What are the block range limits for eth_getLogs queries on Pharos?

**Goal:** building an on-chain event monitor

**A (verbatim, 48.11s):**

> For direct Pharos JSON-RPC `eth_getLogs`, the documented range is **100 blocks when rate limiting is enabled**, with a **10,000-block fallback cap**. See [JSON-RPC API Methods](/api-and-sdk/json-rpc-methods).

> If you’re using the Pharos MCP `get_logs` tool instead, its limit is **1,000 blocks per call**. See [Pharos MCP](/tooling-and-infrastructure/mcp). For an event monitor, split historical scans into chunks within the limit for your endpoint.

## Q6-skillengine

**Q:** How do I install, build and publish a skill with the Pharos Skill Engine?

**Goal:** publishing an agent skill

**A (verbatim, 21.39s):**

> Install the Skill Engine locally, add your capability, then upload the Skill package to Anvita Flow for review. The [Pharos Skill Engine](/tooling-and-infrastructure/pharos-skill-engine-guide) covers building the capability; [Publish Service Agent](/tooling-and-infrastructure/overview/publish-skill-af) covers hosted publishing.
> 
> 1. **Install the engine and prerequisites.** Unzip the Skill Engine package and enter its directory:
> 
>    ```bash
>    unzip pharos-skill-engine-0.1.0.zip
>    cd pharos-skill-engine-0.1.0
>    ```
> 
>    Install Foundry if needed, then verify `cast` and `forge` are available. Keep wallet keys in an environment variable; never commit them.
> 2. **Build your capability.** For a new on-chain operation, add its contract or assets, write detailed instructions in `references/<skill>.md`, and add matching user-intent rows to the Capability Index in `SKILL.md`. Compile contract changes with:
> 
>    ```bash
>    forge build
>    ```
> 
>    The guide’s publishing checklist also calls for testnet deployment and contract verification where applicable.
> 3. **Package the Skill.** Ensure the package has an uppercase `SKILL.md` with `name` and `description` frontmatter. The `name` must match the package folder name exactly, including case. Zip the **entire folder**, so the zip contains the folder and its `SKILL.md`. A Service Agent currently hosts one Skill package.
> 4. **Debug and submit for publishing.** Sign in at [Anvita Flow](https://flow.anvita.xyz/home), open the [Developer Console](https://flow.anvita.xyz/service-agents), and choose **Create A Managed Service Agent**. Upload the zip, configure the service strategy and runtime, then run at least one successful end-to-end debug session. Complete the Agent Card and submit it for review. It goes live after approval; the list shows **Published / Running**. During the earnings beta, the guide recommends setting the call price to **Free** to avoid call failures.
>

## Q10-verify

**Q:** How can I verify a transaction or check an address balance on the Pharos block explorer?

**Goal:** estimating fees and reading chain data

**A (verbatim, 36.4s):**

> Use the [Hemera SocialScan explorer](https://pharos.socialscan.io/), listed as Pharos’s official explorer in the [Hemera SocialScan](/tooling-and-infrastructure/block-explorer/hemera-socialscan).

> * **Check an address balance:** Search for the wallet address and open its address page. It shows the PROS balance and address activity, as described in [Get PROS Gas](/getting-started/get-pros-gas).

> The explorer also supports inspecting blocks, smart contracts, and token activity. ([Block Explorer](/tooling-and-infrastructure/block-explorer))
