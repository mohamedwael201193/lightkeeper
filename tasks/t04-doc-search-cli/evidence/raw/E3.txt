For **Pharos Atlantic Testnet**, get testnet `PHRS` from the **Pharos faucet** or directly from the Pharos team. The docs don’t specify a faucet URL. Add the testnet using chain ID `688689` and RPC `https://atlantic.dplabs-internal.com` ([Atlantic Testnet](/getting-started/network/atlantic-testnet)).
